📋 Pravidla a předložky pro zkoušku A2

2. Pád (Genitiv)
Předložky: do, od, z, bez, u, vedle, během
3. Pád (Dativ)
Předložky: k/ke, díky, proti, naproti, kvůli
4. Pád (Akuzativ)
Předložky: na, pro, za, o, v (pohyb, cíl)
6. Pád (Lokál)
VŽDY s předložkou: v/ve, na, o, po, při
7. Pád (Instrumentál)
Předložky: s/se, před, za, pod, nad, mezi
